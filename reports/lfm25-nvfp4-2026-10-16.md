# LFM2.5 NVFP4 benchmark — 2026-10-16

Added profile: `lfm25`, alias `lfm2.5-24b-a2b-nvfp4`.
All six fresh-process runs passed with **131072 server context**, full layer offload,
Flash Attention, FP16 K/V, batch/microbatch 4096/1024, Direct I/O and no speculation.
The GGUF has no embedded MTP head. Existing Swift/Qwen profile files are unchanged.

## Model and runtime

- Model: [WhiskyAKM NVFP4 GGUF](https://huggingface.co/WhiskyAKM/LFM2.5-24B-A2B-NVFP4-GGUF/tree/1e9f2a188139a79d42a6a3533cf7b61d3778a3f8).
- SHA256: `f29ed107747c75becc40e5bb68efad840bd14f59d72e39264a5f502ac6376483`; 13,578,191,136 bytes.
- Runtime: b11433 CUDA 12.8, commit `50569eb87`; binary SHA256 `a2bd95e075b90541548148538e02436d521da7306e56f2a305df89c4d5e52a7d`.
- RTX 5090 Laptop GPU, 24 GB; NVIDIA driver 590.70 (Windows driver 592.27).
- Binary reports `BLACKWELL_NATIVE_FP4 = 1`; activation precision uses runtime/model defaults (`auto`). No forced W4A4.
- Model GPU buffer: 12,941.30 MiB; FP16 KV buffer: 2,560 MiB; compute buffer: 426.03 MiB.

## Workload and results

Three fresh server processes per input size, sequentially: 36864 tokens first, then 98304.
Synthetic varied Python service modules, tokenized by LFM; 512 generated tokens per run,
EOS ignored, seed 42. Every run evaluated the entire prompt with `cache_n=0` and no truncation.
Temperature 0.1, top-k 50, repetition penalty 1.05 are explicitly set in the profile and requests,
following the model page. Response generation settings confirmed all three values.
Other sampling settings use runtime defaults. This is a speed probe, not a coding-quality evaluation.

| Input tokens | Server context | Runs | Median prefill tok/s | Median decode tok/s | Median prefill seconds | Peak total GPU GiB |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 36864 | 131072 | 3 | 8940.9 | 149.5 | 4.123 | 17.22 |
| 98304 | 131072 | 3 | 6797.4 | 114.9 | 14.462 | 17.29 |

Individual prefill/decode rates (tok/s):

- prompt36864-r1: 8940.9 / 149.5.
- prompt36864-r2: 8236.7 / 157.5.

GPU telemetry includes display/background allocations. Minimum free GPU memory was
6430 MiB across all trials; maximum sampled temperature was 63 C. Host scope memory
peaked below 1.1 GiB, with the existing 6/8 GiB high/max limits and swap disabled.
The 36K and 96K trials were sequential rather than interleaved; laptop power and
heat behavior can affect these measurements. No alternative quant was benchmarked,
so these results do not establish an NVFP4 speedup over Q4 or IQ quants.

## Reproduce

```bash
python3 llama.py install lfm25
python3 llama.py verify lfm25
python3 llama.py smoke lfm25
python3 experiments/lfm_benchmark.py
```

Launch the 128K profile with `python3 llama.py start lfm25`.
Raw timings, token arrays, outputs, commands and telemetry are in
`logs/lfm25/benchmark-20261016-103447/` (ignored by Git).
