Each column is one run. B2 reached 67,872 prompt tokens; its long-context bucket is omitted. Initial prefill was 9,902 tokens; later prefill excludes it. Post-warm-up start temperatures varied, and model-generated workloads differed. These observations do not isolate the effect of unified KV.

Checkpoint and prompt-cache observations

Each run retained at most two 149.626 MiB checkpoints in the active slot (299.252 MiB). Each logged a peak prompt-cache occupancy of 450.848 MiB. These figures can include related state and must not be added as measured total host memory.

Median checkpoint restore log brackets were 26.7 ms (A1), 26.4 ms (B1), 24.0 ms (C1), and 25.4 ms (partial B2). These intervals include checkpoint checking and are not isolated restore timings. Checkpoint creation duration was not logged. The broader prompt-cache update timings are described in the A1 baseline and ignored raw run evidence.

GPU temperature was sampled at one-second intervals. The reason sampler for A1 began about 21 seconds after the thread; the main GPU sampler covered the full run. Start temperatures were recorded after warm-up. No fan RPM was available.

The C1 initial full prefill was not flagged as reprocessing in the server log. It has been excluded explicitly from its later-turn prefill rows, matching the other runs. The pinned b12001 build predates the upstream flash-attention rows change; this test does not isolate a previously occupied long second slot.
